[00:00:05] Today we will study how neural networks learn. A neural network is a function built from layers of simple units called neurons, and each neuron computes a weighted sum of its inputs followed by a non-linear activation function.
[00:00:40] Why do we need the activation function? Without it, stacking layers would still give a linear model. Common choices are ReLU, sigmoid and tanh. ReLU outputs zero for negative inputs and the input itself for positive ones, and it is popular because it is cheap to compute and reduces the vanishing gradient problem.
[00:01:30] To train the network we need a loss function, which measures how far the predictions are from the true labels. For classification we usually use cross-entropy loss, and for regression we use mean squared error.
[00:02:10] Learning means adjusting the weights to reduce the loss. We do this with gradient descent: compute the gradient of the loss with respect to each weight, then move the weights a small step in the opposite direction. The size of that step is the learning rate. If it is too large, training diverges; if it is too small, training is very slow.
[00:03:05] The gradients are computed efficiently by backpropagation. Backpropagation applies the chain rule of calculus layer by layer, starting from the output and moving backwards, so that we reuse intermediate results instead of recomputing them.
[00:03:50] In practice we do not use the whole dataset for each step. Mini-batch gradient descent uses a small batch of examples per update, which is faster and adds helpful noise. One full pass through the dataset is called an epoch.
[00:04:30] Finally, overfitting happens when the model memorises the training data and performs poorly on new data. We detect it using a validation set and reduce it with regularisation, dropout or early stopping.
